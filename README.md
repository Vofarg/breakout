# 🧱 Арканоид · Neon Edition

Классический арканоид в одном HTML-файле: мячик разбивает кирпичи, отталкиваясь от платформы. Не дай ему улететь вниз — это Game Over.

**▶ Играть:** откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

## Возможности

- **3 уровня** от простого к сложному: «Разминка», «Крепость» (кирпичи на 2 удара), «Лабиринт» (кирпичи на 3 удара, неразрушимые и движущиеся препятствия)
- **Счёт и таблица рекордов** (топ-5, хранится в браузере)
- **5 бонусов**, которые иногда выпадают из кирпичей — их нужно поймать платформой
- **Понятная скорость:** каждые 8 разбитых кирпичей мячик ускоряется на 6% (максимум +30%), индикатор ⚡ на поле
- **Светлая и тёмная тема**, неоновый дизайн, шрифт Unbounded
- **Экран победы** с конфетти после прохождения всех уровней
- **Адаптивность:** работает на компьютере, планшете и телефоне, в любой ориентации

## Управление

| Действие | Клавиатура | Мышь | Сенсор |
|---|---|---|---|
| Двигать платформу | ← → | движение курсора | вести пальцем по полю |
| Запустить мячик | Пробел | клик | тап по полю |
| Пауза | P | кнопка ⏸ | кнопка ⏸ |
| Рестарт | R | кнопка «Рестарт» | кнопка «Рестарт» |
| Сменить тему | T | кнопка 🌙 | кнопка 🌙 |

## Бонусы

| | Бонус | Эффект |
|---|---|---|
| ×3 | Мультибол | +2 мячика |
| 🔥 | Огненный шар | 7 с пробивает кирпичи насквозь без отскока |
| ↔ | Широкая платформа | платформа в 1,5 раза шире на 12 с |
| ⏳ | Замедление | мячики медленнее на 10 с |
| 🛡 | Щит | энергетический барьер внизу один раз спасает мячик (до 20 с) |

## Технологии

Чистые HTML, CSS и JavaScript (Canvas 2D), без библиотек и сборки. Физика работает с фиксированным шагом 60 обновлений в секунду, поэтому скорость одинакова на экранах 60, 90 и 120 Гц.
